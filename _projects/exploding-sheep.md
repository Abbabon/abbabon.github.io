A free, browser-playable puzzle game: guide a shepherd through a minefield,
using sheep as shields and Minesweeper logic that's been gently bent to be
fun (the numbers only count mines up/down/left/right - never diagonals).
Moshe Gilboa's brainchild; I was one of the programmers. Built in Unity.
